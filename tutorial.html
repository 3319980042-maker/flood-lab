第一次，按这6步操作

打开网站选择“访客体验”。想一边操作一边看提示，可点击平台顶栏的“新手教程”，选择“第一次协同演练”。

01 / START

选脚本，开始演练

进入演练中心 → 指挥大屏，点击“选择脚本 / 新建演练”。第一次选“01 · 暴雨应急协同”，确认开始。

看到：演练时间T+0，地图下方出现第一项任务。

02 / DISPATCH

给第一项任务派遣力量

向下找到“情景与任务”，阅读第一项任务的人员、车辆和物资需求。点击“派遣”，第一次保留默认数量并确认。

看到：地图出现出动路线，可用力量减少，队伍进入在途状态。

03 / ADVANCE

推进到任务完成

回到顶部操作条，连续点击“+5 分钟”，观察队伍先到场、再作业。第一套脚本的第一项任务通常在约T+30分钟完成。

看到：任务状态变为“已完成”，完成数增加。到场本身不等于任务完成。

04 / REPORT

提交执行反馈和答案

在第一项任务上点击“执行 / 答题”，说明采取的措施、处置结果和交接情况，按自己的判断作答并提交。

看到：反馈保存在“执行与答题”记录中，题目按规则参与评价。

05 / REVIEW

查看并导出报告

进入评估复盘 → 演练评估，查看任务完成情况和评分依据。可以点击“导出 Word 报告”；也可导出HTML后打印为PDF。

看到：每项任务的状态、评分与建议。未完成任务会如实保留，不会因导出自动结束。

06 / REPLAY

回看自己的操作

进入评估复盘 → 过程回放，拖动时间轴或自动播放，查看之前的任务、力量、标绘与天气。之后返回指挥大屏继续演练。

看到：历史状态随时间轴变化，当前演练进度保持不变。

第一次无需先创建联机房间，也无需先编制资源库。预置脚本已经可以直接体验。右上角可切换本机角色；第一次建议使用“导调”。

想做孤岛识别？走“教学实验”这条路线

教学实验练习道路抢通决策，与协同演练分别记录进度。平台内的新手教程也提供逐页导览。

01 / IDENTIFY

先判断哪些区域到不了基地

进入教学实验 → 灾情识别。绿色道路可通，橙色限行仍可通，红色阻断不可通。选择无法通过可通行道路到达基地S的人口区域，再提交识别。

注意：识别要在派遣、推进之前完成。系统同时检查漏选和误选。

02 / PLAN

同页规划和派遣

进入规划调度，查询通道，点击阻断路段加入计划并安排顺序；向下找到“抢修派遣台”，选择匹配的道路、桥梁或排涝队伍。

检查：工种匹配、队伍空闲、预算足够，且至少一个作业端点可从基地到达。

03 / SIMULATE

推演并调整方案

进入推演训练，每次推进5分钟，观察道路恢复、人口可达性与突发事件。需要调整时暂停，返回规划调度。

想独立考核，再进入“决策考核”。关键决策出现时，先作答再继续。

04 / REFLECT

看教学成绩，保存记录

进入评估复盘 → 教学成绩，看分项评价，完成知识检查与复盘。需要以后继续，在实验记录中保存，或导出备份。

注意：教学报告在“教学成绩”，协同演练报告在“演练评估”。

孤岛识别采用12个预设节点、17条教学道路的连通性计算。徐州地图提供地理背景；当前没有根据真实洪水淹没范围自动生成孤岛。

刚开始最容易遇到的问题

为什么队伍已经到场，任务还没完成？

需要同时满足人员、车辆和物资需求，并完成规定作业时长。到场只代表开始现场处置，继续推进时间后再看作业进度。

为什么按钮是灰的，或提示资源不足？

先看当前角色和演练状态：导调负责启动、推进与投放；正在进行的演练会锁定资料编辑。检查队伍是否已被其他任务占用，以及本次派遣数量是否超出可用资源。暂停状态需先继续。

地图怎么从平面变成三维？

滚轮拉近，或点击“湖滨街区”“重点设施”，也可以选择“三维建筑”。右键拖动调整方向与倾角。小圆点是地面位置，图标和文字通过引线连接。

为什么我选不了孤岛识别答案了？

请先识别，再派遣和推演。时间已经推进或已经投入预算后，初始识别会锁定；决策考核提交后也会锁定答案。保留已有记录，需要重新练习时再明确创建新实验。

我要多人一起用，直接发网址就可以吗？

静态网址支持单机演练。多人房间需要部署后端，或在可信局域网运行随附的Node.js服务，然后在“演练中心 → 联机协作”用六位演练码加入。不同成员建议用独立浏览器会话。

记录存在哪里？换了网址还能接着用吗？

单机记录保存在当前浏览器、当前网址。换设备或网址前，在“内容管理 → 数据备份”导出协同演练JSON，再到新位置导入；教学实验备份在“评估复盘 → 实验记录”导出与恢复。

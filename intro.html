ABOUT THE PROJECT / 项目简介

识别交通孤岛
抢通生命通道

洪涝灾害虚拟仿真实验教学平台

从徐州云龙湖区域地图拉近到三维街区，观察医院、社区和养老院的通道关系。在模拟灾情中识别受困区域、规划抢通顺序、调度专业队伍，观察不同决策的后果，并获得可解释的考核评分。

LEARNING MODES

两种学习方式

从协同处置，到独立决策

01

协同演练

用情景、资源、题目和时间节点编排脚本。导调、总指挥、救援、医疗、保障、评估与观摩七类角色协同完成任务，记录指令、派遣、反馈与会商过程。

本机可切换角色 · 启动随附服务可联机演练
02

决策考核

阅读道路状态，识别与救援基地断连的聚落，在有限的时间和预算下安排抢通顺序。面对动态险情调整方案，并通过分项成绩解释决策效果。

LEARNING JOURNEY

从看懂灾情，到解释每一次决策

识别 → 行动 → 反馈，形成完整学习过程

  1. 01 / IDENTIFY

    识别交通孤岛

    阅读道路状态，判断哪些聚落无法到达救援基地。

  2. 02 / PLAN

    规划与调度

    匹配抢修工种，在有限预算下安排抢通顺序。

  3. 03 / DECIDE

    动态决策

    面对新增险情和通道变化，调整行动方案。

  4. 04 / REFLECT

    评分与复盘

    查看恢复时效、重点保障与操作记录，回放过程并导出报告。
